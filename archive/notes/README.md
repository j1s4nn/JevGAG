# notes/ — working notes

Internal, non-authoritative working notes for the JevGAG project. They are kept in-repo for
transparency and continuity, but the **authoritative** record is:

- the audited result files under [`../results/`](../results/),
- the experiment scripts under [`../scripts/`](../scripts/),
- the manuscript under [`../paper/`](../paper/).

| File | What it is |
|---|---|
| `DESIGN.md` | Design ledger: every RQ / hypothesis / precondition / experiment side by side with its verdict |
| `FINDINGS.md` | Running findings per experiment (E1–E9) |
| `REFERENCE.md` | Reference notes: pinned commits, manifests, protocols, environment |

> These files may lag the code and results. If they disagree with `results/`, `results/` wins.
